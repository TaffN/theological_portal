## How the manuals are kept

- **Editing copy:** each manual is a shared Claude Doc, where we write and comment:
  [Student](https://claude.ai/code/artifact/e5a9184d-2dfc-4b0c-9a67-c25e77bd68f1) ·
  [Lecturer](https://claude.ai/code/artifact/e21e380f-2042-4393-9168-fff151920118) ·
  [Administrator](https://claude.ai/code/artifact/1b24d7ef-a3f2-4a33-9194-39454045dcc6)
- **Released versions:** when a round of changes is agreed, the manuals are saved here on the
  `docs/user-manuals` branch with a new version number and a line in the change log below.
  Git keeps every earlier version.
- **Version numbers:** `1.1`, `1.2`... for corrections and small additions; `2.0` when a new part of the
  portal is added (a new stage) or pages change enough that the screenshots are retaken.
- Each manual's header says which portal version it describes.
